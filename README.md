# hannahcapone.github.io

Source for my portfolio site, live at https://hannahcapone.github.io/.

Plain HTML, CSS and JavaScript with no build step. GitHub Pages serves the `main` branch as is.

## Files

- `index.html`: the site (intro, work, projects, about, contact)
- `about.html`: standalone About page
- `assets/site/style.css`: all styles
- `assets/site/ascii.js` and `name-art.js`: the ASCII name in the header
- `assets/site/fx.js`: hand-drawn marks that draw in as you scroll
- `images/`, `videos/`: project thumbnails and photos

## Run it locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
